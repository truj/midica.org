Breaking Changes between Midica Versions

This page tracks breaking changes between Midica versions.

Midica 1.6.0

Chord Separator and Pattern Index Separator

The default symbol for a chord separator and a pattern index separator was , in Versions older than 1.6.0.

With 1.6.0 these 2 symbols have changed to /.

This change enables us to pass a chord to a function or pattern as a parameter.

A redefinition of PATTERN_INDEX_SEP is not possible any more and not needed either.

CHORD_SEPARATOR and PATTERN_INDEX_SEP are now united in the same symbol.
